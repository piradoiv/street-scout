## How to build the app

Street Scout has been built using [Xojo](https://www.xojo.com).

![Xojo IDE](https://github.com/user-attachments/assets/964306f5-dad1-4996-a94d-41787c191137)

You can download a copy of the IDE and run and debug the app directly on your phone. Building the app for distribution requires a Xojo License.

## How to Contribute

We welcome contributions from the community! There are several ways you can help improve Street Scout:

### 🐛 Report Bugs & Request Features

Found a bug or have an idea for a new feature? Please let us know!

- **GitHub Issues**: Visit our [Issues page](https://github.com/piradoiv/street-scout/issues) to report bugs or request features
- **Email**: Contact us at street-scout at rcruz dot es for sensitive issues

When reporting bugs, please include:
- Street Scout app version
- iOS version and device model
- Clear description of the issue
- Steps to reproduce the problem

### 💻 Code Contributions

Want to contribute code? Here's how to get started:

1. **Development Setup**: Download [Xojo IDE](https://www.xojo.com) (free for development)
2. **Fork & Clone**: Fork this repository and clone it locally
3. **Open Project**: Open `StreetScout.xojo_project` in Xojo IDE
4. **Make Changes**: Implement your improvements or fixes
5. **Test**: Run and test the app on your device
6. **Submit PR**: Create a pull request with a clear description of your changes

**Note**: Building for distribution requires a Xojo License, but you can develop and test freely.

### 📖 Documentation

Help improve our documentation:
- Fix typos or unclear instructions
- Add new guides or tutorials
- Improve code comments
- Translate documentation to other languages

### 🧪 Testing & Feedback

- Test new features and report issues
- Try the app in different scenarios and environments
- Provide feedback on user experience
- Help reproduce reported bugs

### 💡 Other Ways to Help

- **Share**: Tell others about Street Scout
- **Review**: Leave a review on the App Store
- **Support**: Consider [sponsoring the project](https://github.com/sponsors/piradoiv)
- **Community**: Help answer questions in Issues and discussions

### Community Guidelines

- Be respectful and constructive in all interactions
- Follow the existing code style and conventions
- Write clear commit messages and PR descriptions
- Help maintain a welcoming environment for all contributors

Thank you for helping make Street Scout better for everyone! 🗺️
